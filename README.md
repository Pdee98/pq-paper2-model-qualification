Research prototype for an unpublished study (Paper 2; Appiah, Opoku and Asare, Kumasi Technical University). Results are not yet published or peer-reviewed. This bundle activates only the manual paper2-model-qualification workflow: choose Actions, select that workflow, and Run workflow on main, with no inputs. SCALE, Phase C and G2 run sequentially; a failed gate stops qualification. Production validation remains blocked in the source; this bundle contains no production workflow.
